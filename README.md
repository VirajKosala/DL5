### 1. Simple RNN – Next Value Prediction
Implemented a basic Recurrent Neural Network (RNN) to learn patterns from a small numerical sequence and predict its next value. 
This demonstrates how RNNs process sequential data while maintaining information from previous time steps.

### 2. LSTM – Time-Series Forecasting
Implemented a Long Short-Term Memory (LSTM) network for time-series forecasting. 
The model learns long-term dependencies and temporal patterns from historical time-series data to predict future values.

### 3. LSTM – Sentiment Analysis
Implemented an LSTM-based sentiment analysis model to classify text according to its sentiment.
The model processes sequences of words and learns contextual relationships to determine whether a given text expresses a positive or negative sentiment.
